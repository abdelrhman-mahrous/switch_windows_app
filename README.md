# Switch

تطبيق ويندوز بسيط لتصحيح النص المكتوب بلغة كيبورد غير مقصودة بين العربية والإنجليزية.

## التشغيل

```powershell
python -m pip install -r requirements.txt
python switch_app.py
```

من نافذة الإعدادات:

1. اضغط **تسجيل** بجانب الوظيفة المطلوبة، ثم اضغط الاختصار الذي تريده على كيبوردك.
2. اضغط **حفظ الإعدادات**.
3. داخل أي برنامج، اكتب النص واضغط اختصار التحويل مباشرة. لو لم تحدد نصًا، سيحوّل التطبيق تلقائيًا الكلام من بداية السطر حتى مكان المؤشر.
4. يمكنك أيضًا تحديد جزء معين من النص لتحويل هذا الجزء وحده.

مثال: كتابة `hgsghl ugd;l` ثم ضغط اختصار التحويل تستبدلها مباشرةً بـ `السلام عليكم`.

إغلاق النافذة لا يغلق التطبيق؛ يظل موجودًا بجوار الساعة. اختر **خروج** من أيقونة Switch لإغلاقه بالكامل.
